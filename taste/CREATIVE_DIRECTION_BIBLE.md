# Zlog Creative Direction Bible v0.1

## 1. Zlog가 만드는 것은 컷 모음이 아니다

Zlog는 좋은 장면을 음악에 맞춰 나열하는 자동 편집기가 아니다.

Zlog는 흩어진 사진과 영상에서 하나의 중심 감정과 사건의 흐름을 발견하고, 사용자가 의식하지 못할 정도로 자연스러운 서사를 만든다.

모든 결과물에는 다음이 존재해야 한다.

* 영상의 목적
* 첫 장면을 선택한 이유
* 장면이 진행되는 순서
* 감정 또는 정보의 변화
* 가장 중요한 순간
* 끝내야 하는 이유
* 영상을 본 뒤 남는 여운

편집 구조는 존재해야 하지만 템플릿처럼 보여서는 안 된다.

# 2. Zlog Soft Flow

모든 영상은 목적에 맞는 부드러운 흐름을 가진다.

기본 흐름:

1. Hook
2. Orientation
3. Development
4. Zlog Moment
5. Release
6. Resonance

## Hook

시청자가 영상을 계속 봐야 할 이유를 만든다.

강한 자막이나 자극적인 효과만을 의미하지 않는다.

가능한 Hook:

* 예상 밖의 행동
* 카메라와 피사체의 교감
* 아름다운 움직임
* 결과를 먼저 보여주는 cold open
* 소리로 시작하는 장면
* 의미가 궁금해지는 불완전한 장면

첫 장면은 단순히 가장 예쁜 장면이 아니라, 다음 장면을 보고 싶게 만드는 장면이어야 한다.

## Orientation

시청자가 다음을 자연스럽게 이해하도록 한다.

* 어디에 있는가
* 무엇을 하고 있는가
* 누구 또는 무엇이 중요한가

설명 자막으로 직접 말하기보다 공간, 행동, 소리와 연결 장면으로 보여준다.

## Development

장면마다 작은 변화가 있어야 한다.

* 장소의 변화
* 행동의 진행
* 피사체와의 거리 변화
* 감정적 온도의 변화
* 음악 에너지의 변화
* 정보의 추가

같은 의미의 장면을 반복하지 않는다.

## Zlog Moment

전체 원본에서 가장 기억할 가치가 있는 순간이다.

반드시 가장 화려하거나 기술적으로 완벽할 필요는 없다.

가능한 Zlog Moment:

* 웃음이 시작되는 순간
* 강아지가 카메라를 바라보는 순간
* 문이 열리며 공간이 드러나는 순간
* 커피가 컵에 닿는 순간
* 바람에 옷이나 머리카락이 움직이는 순간
* 초점이 잡히며 피사체가 선명해지는 순간
* 계획하지 않았던 작은 실수
* 말이 끝난 뒤 남는 잠깐 표정

Zlog Moment 전에는 충분한 맥락을 제공하고, 순간이 지나간 뒤에는 짧은 여운을 남긴다.

## Release

Zlog Moment 이후에는 계속 자극을 높이지 않는다.

편집 속도, 음악 또는 화면 움직임을 조금 풀어준다.

시청자가 방금 본 장면을 받아들일 시간을 준다.

## Resonance

엔딩은 영상이 단순히 중단된 것처럼 보여서는 안 된다.

마지막 장면은 앞의 장면과 의미적, 시각적 또는 청각적으로 연결되어야 한다.

가능한 엔딩 방식:

* 첫 장면의 시각적 요소를 다시 보여준다.
* 시작과 반대 상태를 보여준다.
* 행동이 끝난 뒤의 고요함을 보여준다.
* 인물이 프레임 밖으로 나가도록 둔다.
* 자연음만 남기고 음악을 사라지게 한다.
* 움직임이 끝나기 직전에 검은 화면으로 전환한다.
* 질문이나 감정을 완전히 설명하지 않고 여지를 남긴다.
* 다음 순간이 존재할 것 같은 상태로 끝낸다.

엔딩은 모든 것을 설명하지 않는다.
완결감과 여운을 동시에 제공한다.

# 3. 영상 효과의 역할

Zlog는 효과를 장식으로 사용하지 않는다.

모든 효과는 다음 목적 중 하나 이상을 가져야 한다.

* 시선을 특정 요소로 유도
* 중요한 말이나 문장에 집중
* 시간 또는 장소의 변화 표현
* 동작의 에너지 강화
* 감정의 전환 표현
* 현실과 기억의 구분
* 장면 사이의 의미적 연결
* 엔딩의 여운 강화

목적을 설명할 수 없는 효과는 사용하지 않는다.

## 예시: 블러 후 자막 표시

사용 조건:

* 화면 정보가 많아 자막 집중이 어려움
* 자막 자체가 중요한 서사적 전환임
* 장소나 시간이 바뀌었음을 알려야 함
* 원본 장면을 잠시 배경으로 사용해야 함

연출:

1. 원본 화면을 짧게 보여준다.
2. 화면을 부드럽게 블러 처리한다.
3. 자막을 표시한다.
4. 자막을 읽을 충분한 시간을 둔다.
5. 블러를 제거하거나 다음 장면으로 연결한다.

금지:

* 모든 자막에 반복 사용
* 의미 없는 확대와 함께 사용
* 읽을 시간 없이 빠르게 제거
* 화면 자체가 더 중요한 순간에 사용

## 효과 예산

영상 전체에 사용할 강한 효과의 수를 제한한다.

* 15초 영상: 강한 효과 최대 2회
* 30초 영상: 강한 효과 최대 3~4회
* 같은 효과를 연속 사용하지 않는다.
* 강한 효과 뒤에는 시각적으로 조용한 구간을 둔다.
* 효과가 Zlog Moment보다 더 눈에 띄면 실패다.

# 4. 자막 규칙

자막은 화면을 그대로 설명하지 않는다.

나쁜 예:

* 카페에 도착했다.
* 강아지를 만났다.
* 커피를 마셨다.

좋은 자막은 화면에 없는 최소한의 맥락이나 잔향을 더한다.

가능한 역할:

* 시간의 흐름
* 짧은 관찰
* 상황의 반전
* 사용자가 실제로 제공한 생각
* 장면을 다르게 보게 하는 한 문장
* 영상의 시작 또는 끝을 묶는 문장

자막을 사용하지 않는 것도 하나의 연출 결정이다.

다음 상황에서는 자막을 넣지 않는다.

* 표정이나 행동 자체가 충분히 전달됨
* 공간과 소리에 집중해야 함
* Zlog Moment가 진행 중임
* 중요한 자연음이 존재함
* 자막이 감정을 과도하게 규정할 수 있음
* 화면 효과와 움직임만으로 의도가 전달됨

자막 없는 구간은 빈 공간이 아니다.
화면, 움직임, 소리 자체에 집중시키는 적극적인 연출이다.

# 5. 오디오 규칙

음악은 영상을 지배하지 않고 장면을 지원한다.

## 대사

의미 있는 사람이 말하는 구간에서는 BGM을 반드시 낮춘다.

단, 다음을 구분한다.

* 주요 발화
* 짧은 감탄이나 웃음
* 의미 있는 현장음
* 배경의 불분명한 대화
* 의미 없는 소음

권장 처리:

* 주요 발화: 강한 ducking
* 웃음과 짧은 반응: 중간 ducking
* 중요한 자연음: 중간 또는 짧은 ducking
* 불분명한 배경 대화: 필요할 때만 약한 ducking
* 의미 없는 소음: 강조하지 않음

볼륨은 갑자기 감소하거나 복구되지 않는다.
attack과 release를 사용해 자연스럽게 변화시킨다.

## 자연음

다음 소리는 가능한 한 보존한다.

* 문이 열리는 소리
* 커피가 내려지는 소리
* 컵이 놓이는 소리
* 바람
* 빗소리
* 발걸음
* 웃음
* 동물의 소리
* 옷과 물체가 움직이는 소리

중요한 자연음 직전에 음악을 낮추고, 자연음이 끝난 뒤 음악의 비트가 다시 들어오면 강한 편집적 만족감을 만들 수 있다.

# 6. 불완전함의 보존

Zlog는 기술적으로 완벽한 장면만 선택하지 않는다.

다음 불완전함은 감성적 가치가 있을 수 있다.

* 적당한 손떨림
* 초점이 잡히는 과정
* 프레임 안팎으로 들어오고 나가는 행동
* 예상하지 못한 카메라 움직임
* 웃다가 카메라를 피하는 순간
* 촬영자가 움직이며 생기는 현장감
* 작은 실수와 반응

흔들림을 무조건 실패로 판단하지 않는다.

다음을 구분한다.

* 의도와 에너지가 느껴지는 흔들림
* 현장감이 있는 handheld motion
* 피사체를 알아볼 수 없는 실패성 흔들림
* 멀미를 유발하는 지속적인 흔들림

감성적 흔들림은 보존할 수 있지만, 시청을 방해하는 흔들림은 제거하거나 짧게 사용한다.

# 7. 편집 결정의 이유

모든 PlannedClip에는 편집 이유가 있어야 한다.

예시:

```json
{
  "segment_id": "S07",
  "role": "zlog_moment",
  "selection_reasons": [
    "DIRECT_GAZE",
    "EMOTIONAL_REACTION",
    "NARRATIVE_PROGRESS"
  ],
  "cut_reason": "피사체가 카메라를 바라본 직후 시선을 피하는 순간에 감정적 변화가 완료됨",
  "caption_strategy": "none",
  "caption_reason": "표정과 자연음 자체에 집중시키기 위함",
  "audio_strategy": {
    "preserve_source_audio": true,
    "bgm_duck": true,
    "reason": "짧은 웃음소리가 장면의 감정적 핵심임"
  },
  "effect_strategy": {
    "effect": "none",
    "reason": "효과가 피사체의 미세한 표정보다 강하게 느껴질 위험이 있음"
  }
}
```

중요한 것은 AI가 장황한 설명을 쓰는 것이 아니다.

* 왜 선택했는가
* 왜 이 위치에서 잘랐는가
* 왜 효과를 넣었거나 넣지 않았는가
* 왜 자막을 사용했거나 사용하지 않았는가
* 왜 음악을 줄였는가

를 구조화된 짧은 이유로 남기는 것이다.

# 8. 목적별 Soft Flow

모든 영상이 같은 구조를 따르지 않는다.

## 일상 브이로그

관찰
→ 작은 변화
→ 개인적 순간
→ 조용한 여운

## 여행 브이로그

기대 또는 도착
→ 공간 발견
→ 활동과 감각
→ 가장 기억에 남는 순간
→ 떠남 또는 회상

## 코미디 브이로그

상황 제시
→ 예상 형성
→ 어긋남
→ 반응
→ 짧은 콜백

## 감성 브이로그

분위기 제시
→ 감각적 디테일
→ 감정적 중심
→ 호흡 완화
→ 설명되지 않은 여운

## 제품·브랜드 영상

시각적 훅
→ 제품 또는 공간 이해
→ 사용 경험
→ 질감과 디테일
→ 브랜드 인상
→ 자연스러운 CTA 또는 로고

목적에 따른 구조는 존재하지만, 장면 수와 타이밍을 고정하지 않는다.

AI는 원본의 실제 내용에 맞춰 흐름을 변형해야 한다.

# 9. Zlog 품질 평가

완성된 영상은 다음 항목으로 평가한다.

* `narrative_coherence`
* `hook_strength`
* `zlog_moment_strength`
* `flow_naturalness`
* `effect_relevance`
* `effect_restraint`
* `caption_restraint`
* `natural_audio_preservation`
* `human_imperfection_value`
* `opening_ending_resonance`
* `template_visibility`
* `emotional_aftertaste`

좋은 Zlog 영상의 조건:

* 서사가 있지만 구조가 노골적으로 보이지 않는다.
* 효과가 있지만 효과 자랑처럼 보이지 않는다.
* 자막이 적어도 영상의 의미가 전달된다.
* 자연음과 음악이 서로 경쟁하지 않는다.
* 기술적으로 불완전한 장면도 필요하면 살아 있다.
* 첫 장면과 마지막 장면이 서로 연결된다.
* 영상이 끝난 뒤 한 장면이나 감정이 기억에 남는다.

실패 조건:

* 모든 비트마다 컷이 발생함
* 모든 장면에 줌 효과가 있음
* 모든 자막에 같은 효과가 반복됨
* 자막이 화면을 그대로 설명함
* 음악이 사람의 말이나 중요한 자연음을 덮음
* 길이를 채우기 위해 장면을 반복함
* 효과가 원본보다 더 눈에 띔
* 영상이 갑자기 끝나거나 단순 크레딧으로 종료됨
* 이야기 없이 예쁜 장면만 나열됨

# 10. Zlog의 최종 원칙

Zlog는 편집을 많이 하는 AI가 아니다.

Zlog는 다음을 아는 AI다.

* 어떤 장면을 남겨야 하는가
* 어느 순간까지 기다려야 하는가
* 정확히 언제 잘라야 하는가
* 언제 음악을 낮춰야 하는가
* 언제 효과를 넣어야 하는가
* 언제 아무것도 하지 않아야 하는가
* 어떤 순간으로 영상을 끝내야 하는가

Zlog의 편집은 눈에 띄지 않아야 한다.

하지만 영상을 다 본 사용자는 이렇게 느껴야 한다.

“그냥 찍어둔 영상이었는데, 하나의 이야기가 됐다.”
